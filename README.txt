RS DIGITAL MARKETING WEBSITE
=============================

FILES
-----
index.html  = website content and page sections
style.css   = colours, layout and mobile responsive design
script.js   = mobile menu, current year and demo contact form
logo.svg    = editable vector logo

HOW TO PREVIEW ON YOUR COMPUTER
-------------------------------
1. Download and extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. It should open in your web browser.
5. To edit the website, open the folder in Visual Studio Code (or another text editor).

IMPORTANT CUSTOMIZATIONS BEFORE PUBLISHING
------------------------------------------
1. In index.html, replace hello@rsdigitalmarketing.com with your real email address.
2. In script.js, change businessEmail to the same real email address.
3. Replace the location if needed.
4. Add your real social media links and real team details if you want them.
5. Do not claim clients, results, testimonials or years of experience unless they are true.
6. The contact form uses mailto. It opens the visitor's email app; it does not save messages to a database.

PUBLISH FREE WITH GITHUB PAGES
------------------------------
1. Create or sign in to a GitHub account.
2. Create a new PUBLIC repository named rs-digital-marketing.
3. Upload index.html, style.css, script.js and logo.svg to the repository's root (not inside another folder).
4. Open the repository's Settings.
5. Select Pages in the left menu.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait a few minutes. GitHub will show your public website address in Settings > Pages.

Your free address will look similar to:
https://YOUR-USERNAME.github.io/rs-digital-marketing/

A custom .com domain usually costs money. GitHub Pages hosting for this static website is free.
